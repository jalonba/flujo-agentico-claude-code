# HU-01 · Calcular horarios libres

**Estado:** Aprobada · **Tamaño:** S · **Capa:** dominio (función pura) · **Depende de:** —
**Verificación:** pendiente (VER-01)

## Historia

Como **persona que quiere agendar**, quiero **saber qué bloques del día siguen libres**, para
**no proponer una hora que ya está tomada o que ya pasó**.

## Contrato

```ts
calcularHorariosLibres({
  apertura: "08:00",       // HH:MM
  cierre: "10:00",         // HH:MM
  duracionMin: 30,         // entero > 0
  citas: Cita[],           // { id, nombre, fecha, inicio, fin }
  fecha: "YYYY-MM-DD",
  ahora: Date,             // reloj inyectado: nunca se lee el reloj del sistema
}): { inicio: string; fin: string }[]   // ordenado por inicio
```

## Criterios de aceptación

| Id | Dado | Cuando | Entonces |
|---|---|---|---|
| HU-01.c1 | apertura 08:00, cierre 10:00, 30 min, sin citas, fecha posterior a `ahora` | se calculan los horarios | se obtienen los 4 bloques `08:00–08:30 … 09:30–10:00`, en orden |
| HU-01.c2 | una cita 08:15–08:45 en esa fecha y otra en una fecha distinta | se calculan los horarios | se excluyen `08:00` y `08:30` (se solapan); la cita de otra fecha no afecta |
| HU-01.c3 | una cita 08:00–08:30 (borde de apertura) y otra 09:30–10:00 (borde de cierre) | se calculan los horarios | solo quedan `08:30` y `09:00`; bloques que solo se tocan en el borde no se consideran solapados |
| HU-01.c4 | apertura 08:00, cierre 09:45, 30 min | se calculan los horarios | se obtienen `08:00`, `08:30`, `09:00`; el bloque `09:30–10:00` no cabe y no se ofrece |
| HU-01.c5 | la fecha es anterior al día de `ahora` | se calculan los horarios | se obtiene `[]` |
| HU-01.c6 | la fecha es el día de `ahora` y `ahora` = 09:10 | se calculan los horarios | solo queda `09:30–10:00`; un bloque cuyo inicio es ≤ `ahora` ya empezó |
| HU-01.c7 | `duracionMin` ≤ 0 o no entero, `apertura ≥ cierre`, o una hora/fecha mal formada | se calculan los horarios | se lanza `RangeError` |

## Reglas de negocio

- Solapamiento: `bloque.inicio < cita.fin && cita.inicio < bloque.fin`.
- La grilla arranca en `apertura` y avanza de a `duracionMin`.
- Las fechas se construyen en hora local con componentes numéricos.
