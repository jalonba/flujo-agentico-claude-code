# HU-02 · Ver la agenda del día

**Estado:** Aprobada · **Tamaño:** M · **Capa:** dominio + lectura de `localStorage` + UI · **Depende de:** HU-01
**Verificación:** pendiente (VER-02)

## Historia

Como **persona que quiere agendar**, quiero **ver los horarios libres y ocupados de la fecha que
elija**, para **decidir rápido a qué hora reservar**.

## Criterios de aceptación

| Id | Dado | Cuando | Entonces |
|---|---|---|---|
| HU-02.c1 | el reloj marca un día y hay una cita guardada ese día | abro la página | el campo **Fecha** muestra ese día y la lista muestra cada bloque futuro con su estado en texto: «Libre» u «Ocupado» |
| HU-02.c2 | la página cargada | cambio la fecha a otro día | la lista muestra los bloques de ese día |
| HU-02.c3 | las citas guardadas aún no se han leído (render inicial / servidor) | se pinta la página | se muestra «Cargando agenda…» con `role="status"` |
| HU-02.c4 | una fecha pasada, o un día sin ningún bloque libre | se muestra la agenda | aparece el estado vacío: «No quedan horarios libres para esta fecha.» |
| HU-02.c5 | lo guardado en `localStorage` no es JSON válido o no tiene la forma de `Cita[]` | se abre la página | aparece un error con `role="alert"` y un botón **Reintentar**; la página no se rompe |
| HU-02.c6 | — | siempre | el campo de fecha tiene `label` asociado; el estado de cada bloque está en texto (no solo color); cada par texto/fondo de los tokens de color cumple contraste WCAG AA (≥ 4,5:1), comprobado por un test |

## Reglas de negocio

- Configuración fija: 08:00–17:00, bloques de 30 min.
- Un bloque ocupado no muestra el nombre de quien reservó (privacidad por defecto).
- Los bloques que ya empezaron no se muestran.

## Datos que toca

Solo lectura de `localStorage["agenda-citas:v1"]`.

## Fuera de alcance
